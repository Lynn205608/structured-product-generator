# 结构化产品介绍生成器

一个基于 Web 的金融结构化产品介绍生成工具，支持多种期权结构类型和可视化损益图。

## 在线访问

GitHub Pages: [点击访问](https://你的用户名.github.io/你的仓库名/)

## 功能特性

- **多种产品结构**：目前支持鲨鱼鳍、二元、价差、香草、自动赎回、红利自动赎回六种结构
- **看涨/看跌双向**：每种结构均支持看涨和看跌两种方向
- **实时损益图**：使用 Chart.js 绘制专业的可视化损益图表
- **PPT 导出**：一键导出产品介绍为 PPT 格式
- **响应式设计**：适配不同屏幕尺寸

## 本地使用

直接双击 `结构化产品介绍生成器.html` 文件即可在浏览器中打开使用。

## 技术栈

- HTML5 + CSS3
- Tailwind CSS
- Chart.js
- PptxGenJS
